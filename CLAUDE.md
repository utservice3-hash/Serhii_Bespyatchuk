## Мої токени (ТІЛЬКИ НА СЕРВЕРІ)
> ⚠️ Токени зберігаються виключно в `/root/my-bot/.env` на VPS.
> Ніколи не записуй їх у файли репо.

- `TG_TOKEN` — Telegram BotFather
- `ANTHROPIC_KEY` — Anthropic API
- `GH_USER` — `utservice3-hash`
- `GH_TOKEN` — GitHub PAT (scope: repo)

## Правила роботи зі мною

1. **Зміни бота** → редагуй файли в `utservice3-hash/my-bot` через GitHub API, потім Relay перезапускає
2. **Нові токени** → одразу зберігай на сервері через Git Relay, не в репо
3. **Одна команда** → якщо треба щось зробити на VPS, давай одну bash-команду
4. **Перевірка** → після змін завжди перевіряй через Relay і показуй логи
5. **Пам'ять** → оновлюй `MEMORY.md` після кожної важливої зміни
