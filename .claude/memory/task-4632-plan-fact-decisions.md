Рішення:
- Середній чек: ціль ПО КОМАНДАХ, руками не вбивається. Ціль = чек команди за 3 останні повні місяці + 5%, перерахунок на початку місяця (фіксуємо), команда — за поточним складом; <30 успішних угод за 3 міс → цілі немає, лише факт. Чек = маржа «Успішно реалізовано» за датою переходу ÷ угоди (мінусові віднімаються).
- Дзвінки: розмови + спроби (як callNorm, мотивація з 01.10); одна норма на всіх — 45 на день.
- Норма дзвінків живе в «Планах» (ТЗ п.2.5), КВП ставить САМА (без окремого затверджувача), діє до наступної зміни; поле в «Налаштуваннях» стає read-only дзеркалом.
- План тижня — ДИНАМІЧНИЙ (як 5146), на екрані підписати «узгоджено в задачі 5146». ТЗ 28.09 казав «місяць ÷ робочі тижні» — перекрито.
- План на день на графіках — робити (ТЗ п.2.1 «місяць → тиждень → день»).
