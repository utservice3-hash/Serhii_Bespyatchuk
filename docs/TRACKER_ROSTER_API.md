# Реєстр людей для таймтрекера (`/api/auth/tracker-users`)

Опис для розробника таймтрекера. Додано 23.11.2026 разом із полем `office` (задача 10740).

## Запит

```
GET https://dashboard.uts.ua/api/auth/tracker-users
X-Dashboard-Sso-Key: <ключ трекера>
```

- без ключа або з чужим ключем: `401 {"error":"bad_key"}`;
- ключ не налаштований на стороні дашборда: `503 {"error":"not_configured"}`.

Параметрів запиту немає. Часу зміни (`updatedAt`, ETag) у відповіді немає: трекер бачить зміни на наступному повному опитуванні.

## Відповідь

`200 {"people": [ ... ]}` — кожен акаунт дашборда (і активний, і вимкнений), відсортовано за поштою. Приклад: [tracker-roster.example.json](tracker-roster.example.json).

| поле | тип | що означає |
|---|---|---|
| `id` | number | id акаунта в дашборді; трекер зберігає його в `dashboard_user_id` |
| `email` | string | пошта входу; за нею йде зіставлення |
| `name` | string | імʼя (менеджер Kommo → ПІБ акаунта → пошта), `null` не буває |
| `active` | boolean | акаунт увімкнено |
| `trackerEnabled` | boolean | людині відкрито трекер |
| `team` | string \| null | команда Kommo акаунта |
| `scope` | `"company"` \| `"team"` \| `"own"` | що людина бачить; невідома роль = `own` |
| `office` | boolean | **з 23.11.2026.** `true` = галочка «Офісний» у картці «Найму»: людина працює в офісі, трекер **не чекає від неї даних**. `false` = як раніше. Поле є в кожної людини, `null` не буває; акаунт без картки в «Наймі» (службові, тестові) — `false` |

Набір полів закритий: інших ключів у людині немає й без рішення власника не зʼявиться (гейти `#10740b`, `#323b`).

## Що трекер робить з `office` (рішення Романа 23.11.2026)

- день без даних у людини з `office: true` — позначка «В офісі» (як вихідний), а не «—» і не прогул;
- якщо агент усе одно шле дані — активність показується як завжди, позначка «офіс» біля імені лишається;
- офісних не рахувати в «N з M мали активність», показати окремо «K в офісі»; звітів і нагадувань «не працював» для них не формувати;
- відпустка / лікарняний / вихідний із календаря (`TRACKER_CALENDAR_API.md`) важливіші за «офіс»;
- історії немає: поле означає стан зараз.

Повне ТЗ трекера — у задачі 10740.
