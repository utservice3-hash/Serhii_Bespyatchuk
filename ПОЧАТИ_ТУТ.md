## 2. Доступи (робить власниця — вставка в Claude це НЕ надасть)

- **GitHub:** додати нового оператора колаборатором у
  `utservice3-hash/Serhii_Bespyatchuk` (право push).
- **Render** (сервіс `my-bot-8nib`): додати в команду сервісу — **там усі
  секрети** (їх немає в репо).
- **Google Sheets:** за потреби поділитися таблицями (основна + реклама).

**Якщо це той самий бот (переймання)** — env уже налаштований у Render,
міняти нічого не треба, бот уже працює.

**Якщо піднімаєте окрему копію з нуля** — заповніть у Render ці env:

| Env | Для чого |
|---|---|
| `TG_TOKEN` | Telegram-бот |
| `KOMMO_TOKEN`, `KOMMO_BASE` | Kommo CRM API |
| `ANTHROPIC_API_KEY` | Claude (AI-аналіз) |
| `GROQ_API_KEY` | Groq Whisper (транскрибація) |
| `GOOGLE_SHEETS_ID`, `GOOGLE_SERVICE_ACCOUNT_JSON` | Google Sheets |
| `TG_API_ID`, `TG_API_HASH`, `TG_SESSION`, `ELOGIST_SOURCE_CHAT_ID` | userbot eLogist |
| (опц.) `MANAGER_MAP`, `KOMMO_MAX_RPS`, `KOMMO_SYNC_PAUSED` | тюнінг |

> ⚠️ Безпека: у `CLAUDE.md` лежить живий `KOMMO_TOKEN` відкритим. Після
> передачі варто прибрати його з доку (лишити лише в Render env) або ротувати.
