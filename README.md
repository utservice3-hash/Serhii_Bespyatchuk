# Serhii_Bespyatchuk

## leadgen_transcripts

Pipeline that pulls won lead-gen deals from Kommo, matches Ringostat call
recordings by phone number, and transcribes them split by speaker role
(manager vs client).

See [`leadgen_transcripts/README.md`](leadgen_transcripts/README.md) for setup,
the role-separation approach, and how to run it.
