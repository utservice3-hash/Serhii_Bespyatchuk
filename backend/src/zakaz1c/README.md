# «ТЕСТ ЗАКАЗ 1С» — заміна віджета Genesis «Заказ 1С»

26.10.2026. Менеджер у картці угоди Kommo відкриває вкладку **«ТЕСТ ЗАКАЗ 1С»**, заповнює рахунок і тисне
«Створити». Рахунок створюється в 1С, PDF лягає у файли угоди, у стрічці з'являється примітка. Genesis працює
поруч, поки ми тестуємо.

```
Kommo: вкладка «ТЕСТ ЗАКАЗ 1С» (widget/script.js — вікно малюється тут)
  └─ self.$authorizedAjax ─▶ dashboard.uts.ua/api/zakaz1c/…   (Kommo підписує X-Auth-Token секретом інтеграції)
        ├─▶ 1С  customerInfo · POST createInvoice · invoicePdf   (http://193.200.173.188:8010/rest-bk/hs/service)
        └─▶ Kommo API: угода й компанія (ЄДРПОУ), PDF у файли угоди, примітка
```

## Налаштування (env сервера дашборда)

| Змінна | Що |
|---|---|
| `ZAKAZ1C_MODE` | `off` (типово) / `test` / `live` |
| `ZAKAZ1C_TESTERS` | Kommo user id через кому — хто може створювати в режимі `test` |
| `ZAKAZ1C_TEST_EDRPOU` | тестовий контрагент, типово `00100110` |
| `ZAKAZ1C_KOMMO_SECRET` | секретний ключ приватної інтеграції «ТЕСТ ЗАКАЗ 1С» |
| `ZAKAZ1C_KOMMO_CLIENT_UUID` | ID тієї ж інтеграції |
| `ZAKAZ1C_KOMMO_TOKEN` | довгостроковий токен тієї ж інтеграції, з правом «Доступ до файлів» |
| `ONEC_SERVICE_BASE` | адреса сервісу 1С, якщо зміниться |

У налаштуваннях інтеграції в Kommo:

- `testers` = кому видно вкладку.

## Свідомо НЕ робимо (поки Genesis працює поруч)

- Не пишемо в поля Genesis: «Номер заказа», «Оплачено 1с», «Оплачено из 1с», «Код оплаты». Їх пише Genesis, і ми б його перетерли.
- Не рухаємо етапи угод.
- Не робимо оплат з 1С, акта й закриття замовлення: у 1С для цього ще немає методів.
- Не створюємо контрагентів у 1С: `createInvoice` їх теж не створює.

## Відкриті питання

- Точна назва ФОП у 1С. До відповіді Андрія ФОП у списку організацій немає.
- Власні поля угоди, які Genesis передає в рахунок: код оплати, держномер, дата акта, витрати 1–3, канал продажу, тип запиту. У `POST /createInvoice` їх немає. Треба уточнити в бухгалтерії, чи вони потрібні.
- Сервіс 1С відкритий без авторизації. Варто пускати лише сервер дашборда.
